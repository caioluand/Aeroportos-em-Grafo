# Aeroportos-em-Grafo

Objetivo exercitar os conceitos grafos com matriz de adjacência. COm uma estrutura de dados para cadastrar os aeroportos do país e os voos feitos entre os aeroportos. Inicialmente, com os seguintes aeroportos: Belo Horizonte (CNF), Brasília (BSB), Rio de Janeiro (GIG), Salvador (SSA) e São Paulo (GRU), mas comportará quantos forem desejados.

Cadastro e organização dos voos é através de uma matriz de adjacência, sendo esta, um vetor com os aeroportos cadastrados (vértices) e os vôos que os interligam (arestas).
