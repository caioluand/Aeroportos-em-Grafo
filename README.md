# Aeroportos-em-Grafo
Objetivo exercitar os conceitos grafos com matriz de adjacência. Uma estrutura de dados para cadastrar os aeroportos do país e os voos feitos entre os aeroportos. Inicialmente, com os seguintes aeroportos: Belo Horizonte (CNF), Brasília (BSB), Rio de Janeiro (GIG), Salvador (SSA) e São Paulo (GRU), mas comportará quantos forem desejados.
